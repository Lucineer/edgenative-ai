# Edge-Native AI — Agent Runtime for the Edge

You don't need a datacenter to run useful agents near hardware. You just need a lightweight, self-contained runtime.

Most agent frameworks are built for the cloud. This one is built for the edge. It runs entirely on Cloudflare Workers, computes operational trust locally, and translates intent into hardware-ready instructions without external round trips.

**Live Instance:** https://edgenative-ai.casey-digennaro.workers.dev

---

## What It Does

This is a single-file, zero-dependency agent runtime that functions as a trust computer and translation layer for edge systems.

- **Trust Computation** – Each requested operation receives a calculated trust score. Operations deemed unsafe are not executed.
- **VM Emulation** – Sandboxed execution against a minimal 32-opcode stack machine, designed to map to microcontrollers like the ESP32.
- **Intent Translation** – A deterministic, four-stage translation pipeline: Natural Language → Structured Intent → Annotated Bytecode → Hardware Instructions.
- **Knowledge Query** – Local semantic search across a corpus of public NEXUS specifications and documentation.
- **Safety Validation** – All generated bytecode is validated against core safety invariants before being returned.
- **Specifications Server** – Serves version-controlled reference specs for the VM, wire protocol, and safety model.

**One Limitation:** Natural language understanding requires an external LLM API. All other features, including trust scoring, emulation, and safety checks, operate independently.

---

## How It's Different

This is not a general-purpose agent framework.
- **Zero Runtime Dependencies.** Nothing is fetched at boot. It's one file.
- **Calculated Trust.** Trust scores are computed from first principles, not asserted. The logic is auditable.
- **Offline-Validated.** Bytecode that passes validation is designed to run entirely offline on target hardware.
- **Fork First.** No permission needed. Fork it, modify it, and own your complete copy.

## Quick Start

1.  Visit the live instance to test its functions: [https://edgenative-ai.casey-digennaro.workers.dev](https://edgenative-ai.casey-digennaro.workers.dev)
2.  To run your own copy:
    ```bash
    git clone <your-fork-url>
    cd edgenative-ai
    npx wrangler deploy
    ```

**Optional Configuration:** Add API keys (`DEEPSEEK_API_KEY`, `DEEPINFRA_API_KEY`, `SILICONFLOW_API_KEY`) as environment variables in your Cloudflare Worker to enable full natural language input. All other features work without them.
