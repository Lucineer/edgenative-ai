# Edge-Native AI — NEXUS Knowledge Vessel

You don't need a datacenter to run a hardware agent. This single 90kb Cloudflare Worker provides direct access to 1.2 million words of robotics specification, calculates live trust scores locally, and translates natural language into bytecode for compatible hardware. No required round trips to a central server. No vendor lock.

**Live Instance:** https://edgenative-ai.casey-digennaro.workers.dev

---

## Why This Exists
Many agent systems run on remote servers, adding latency between instruction and execution. If you need to control hardware directly, you shouldn't depend on a third-party API that could be slow, unavailable, or altered. This runs at the network edge, adjacent to your devices.

---

## Quick Start
This is fork-first. No account is required to browse. Deploy your own copy in a few minutes:
1.  **Fork** this repository.
2.  Deploy it directly to Cloudflare Workers (fully compatible with the free plan).
3.  Optionally, add your own LLM API keys to enhance natural language understanding for novel requests. All core safety, trust scoring, and validation logic operates without external calls.

---

## Features
*   **Local Trust Scoring:** Calculates a live trust score across 12 parameters within the Worker. The system is designed to penalize unsafe proposed actions 25x more heavily than it rewards safe ones.
*   **Four-Stage Translation Pipeline:** Converts natural language → structured intent → annotated bytecode → final hardware instructions.
*   **Embedded Specification Host:** Serves the complete NEXUS technical specifications (VM, protocol, safety rules) from the edge Worker itself.
*   **Corpus Search:** Provides full-text and semantic search across the embedded 1.2M word specification and research library.
*   **Safety Pre-Flight Check:** Validates every proposed instruction against four configurable tiers of safety rules before execution is permitted.
*   **Embedded Stack VM:** Emulates the 32-opcode NEXUS machine inside the Worker for testing bytecode before sending it to physical hardware.

Zero dependencies. One source file.

---

## What Makes This Different
1.  **No Origin Server:** The Worker is the complete application. There is no backend to call; everything executes at the edge.
2.  **Local Trust Computation:** Trust scores are calculated within your deployed Worker using deterministic logic, not requested from an LLM or remote service.
3.  **Production Bytecode:** The output is not a simulation. The generated bytecode runs on physical ESP32, RP2040, and NEXUS-compatible hardware.

---

## A Specific Limitation
The semantic search is confined to the pre-embedded 1.2M word corpus. It cannot access or retrieve information from the live web or external databases in real-time.

---

## Optional LLM Keys
For extended interpretation of unique or complex natural language requests, you can set `DEEPSEEK_API_KEY`, `DEEPINFRA_API_KEY`, or `SILICONFLOW_API_KEY` as environment variables in your Worker.

All core functionality—safety validation, trust scoring, VM emulation, and specification serving—operates independently without any external keys.
